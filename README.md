# ExileCompass · 流放指南针

面向《流放之路 2》（Path of Exile 2）的 **Path of Building 启动器 + 运行时汉化 + 图鉴工具**。

ExileCompass 不修改 PoB 的任何数据文件：启动时在临时目录生成引导脚本，在 PoB 加载 `Launch.lua` 之前注入汉化模块，用内置字体图集把英文实时渲染成中文；同时提供传奇、词缀、技能等资料的离线图鉴。

- 当前版本：**0.1.1**
- 适配对象：Path of Building Community (PoE2) 0.23.x
- 运行环境：Windows 10/11 x64
- 仓库说明：**本仓库只存放编译好的可运行文件**，源码不在此仓库；安装包见右侧 Releases。

## 一、下载与安装

### 方式 A：安装包（推荐）

1. 打开 [Releases](../../releases/latest)，下载最新的 `ExileCompass-Setup-x.y.z.exe`；
2. 双击安装，按向导完成（默认安装到 `%LOCALAPPDATA%\ExileCompass`）；
3. 从开始菜单或桌面快捷方式启动。

安装包已内置 Qt 运行库，无需额外安装 Qt / VC++ 运行库。

### 方式 B：便携版

1. 下载本仓库的 ZIP（Code → Download ZIP），或直接克隆；
2. 解压到任意目录，双击 `ExileCompass.exe` 即可；
3. 便携版不写注册表以外的位置，卸载直接删除目录。

> 请保持目录结构完整（`platforms/`、`styles/`、`imageformats/`、`tls/`、`networkinformation/`、`pobcn/` 不可删），否则会出现无法启动或界面异常。

## 二、主要功能

### 1. 一键启动 PoB

- 自动在指定根目录下递归扫描（默认 2 层）寻找 PoB 版本目录；
- 校验目录特征：必须同时存在 `manifest.xml`、`Launch.lua`，且具备 `Data/`、`SimpleGraphic.dll` 或 `Path of Building-PoE2.exe` 之一；
- 找到后一键启动，并自动完成汉化注入；
- 支持在「版本列表」页手动指定扫描根目录，扫描结果会持久保存。

### 2. 运行时汉化

- 不改动原 PoB 文件，进程内 hook 绘制函数，按词条实时翻译；
- 支持占位符模板、`^8` 等颜色码、多行文本、`（PoB 暂不支持）` 后缀；
- 未命中的原文原样显示英文，不会丢内容、不会崩溃；
- 汉化可开关，关闭后下次启动即为纯英文原版。

### 3. 图鉴（离线资料库）

- 传奇装备、普通底子、通货、技能石 / 辅助宝石、碑文、地图、保险箱、先祖秘藏日志、遗物、精华与词缀等；
- 支持按物品类型、来源、异界机制筛选，中英文关键词搜索；
- 传奇词条内的专有名词（灵体、附身等）可点击查看说明；
- 数据在首次进入图鉴页时才构建，避免启动卡顿。

### 4. 版本管理 / 公告 / 链接

- 「版本列表」：浏览与切换 PoB 版本目录；
- 「公告」：内置公告页，可用 `ExileCompass.exe` 同级的 `data/announcement.html` 覆盖更新（改完重启即生效）；
- 「链接」：常用站点入口，可自定义编辑、恢复默认。

### 5. 自动更新

- 从 Release 的 `latest.json` 读取最新版本号、下载地址、体积与 SHA-256；
- 下载完成后校验哈希，再拉起安装包（安装包会静默安装并自动重启程序）；
- 更新清单地址：`https://github.com/moonpathbise/Exile-Compass/releases/latest/download/latest.json`。

## 四、目录结构

```
ExileCompass/
├─ ExileCompass.exe            主程序
├─ Qt6*.dll / vcruntime*.dll   Qt 与 MSVC 运行库
├─ dxcompiler.dll              图形编译依赖
├─ platforms/                  Qt 平台插件（勿删）
├─ styles/                     Qt 样式插件
├─ imageformats/               图片格式插件
├─ tls/ 、networkinformation/  网络相关插件（自动更新需要）
└─ pobcn/                      汉化运行时（首次启动时释放）
   ├─ pob_cn.lua               运行时汉化模块（字形绘制 + 词典匹配）
   ├─ atlas.png                字体图集
   ├─ glyphs.tsv               字形度量表
   ├─ custom.tsv               用户自定义词条（不会被覆盖）
   └─ translate/               词典 CSV（运行时自动加载）
```

- `pobcn/` 内的同名文件在升级时**不会被覆盖**，便于保留自己的 `custom.tsv`；
- `custom.tsv` 格式为 `英文<TAB>中文`，优先级最高，可即时补充未翻译词条。

## 五、使用指南

### 1. PoB 目录识别顺序

1. 环境变量 `EXILECOMPASS_ROOT`；
2. 程序所在目录及其最多 4 级父目录；
3. 「版本列表」页手动指定的扫描根目录（保存在 `QSettings` 的 `scanRoot`）。

每个根目录向下搜索 2 层，命中即返回。

### 2. 多版本共存

PoB 便携版建议按版本分目录存放，例如：

```
D:\POB\
├─ PathOfBuildingCommunity-PoE2-0.23.1\
└─ PathOfBuildingCommunity-PoE2-0.23.0\
```

把扫描根指向 `D:\POB`，在「版本列表」中即可看到全部版本。

### 3. 关闭汉化

状态栏或启动页可切换汉化开关；关闭后下次启动即为纯英文原版。图鉴的翻译开关独立，互不影响。

## 六、常见问题

**Q：某些文字仍是英文？**
汉化采用「命中即译」，未收录的原文会原样显示，多为新版本新增的宝石/词条。可在 `pobcn/custom.tsv` 里按 `英文<TAB>中文` 自行补充，重启程序后生效。

**Q：出现方块 / 缺字？**
说明该汉字不在内置字体图集中。请把缺失的文字反馈，或在 `custom.tsv` 中改用已收录的写法。

**Q：启动后没有汉化效果？**
1. 确认汉化开关开启；
2. 查看 `pobcn/cn_lua.log`、`pobcn/boot.log` 是否有加载错误；
3. 确认 PoB 目录下 `Launch.lua`、`manifest.xml` 存在。

**Q：点启动没反应 / 找不到 PoB？**
把扫描根目录指向 PoB 的**父目录**或 PoB 目录本身；也可设置环境变量 `EXILECOMPASS_ROOT` 后重启程序。

**Q：检查更新失败？**
确认网络可访问 GitHub（必要时配置系统代理）。程序通过 `latest.json` 判断版本，只有最新 Release 中的清单才会被读取。

**Q：杀软误报？**
程序未加数字签名，部分杀软会对未签名 exe 提示风险，可加入信任列表。
